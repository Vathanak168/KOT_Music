# 🎵 KOT Music - កម្មវិធីចាក់ចម្រៀង Lock Screen គ្មានពាណិជ្ជកម្ម (100% Ad-Free)

កម្មវិធីចាក់ចម្រៀង YouTube ទំនើប (Web App & PWA) ដែលអនុញ្ញាតឱ្យលោកអ្នកស្ដាប់ចម្រៀង **ដោយគ្មានផ្ទាំងពាណិជ្ជកម្ម (Zero Ads)** និងអាច **ចាក់បន្តនៅពេលបិទអេក្រង់ទូរស័ព្ទ (Lock Screen & Background Audio)** លើទាំង **iPhone (iOS)** និង **Android**។

## ✨ លក្ខណៈពិសេសចម្បង (Key Features)

   - មានប៊ូតុង Play, Pause, Next, Previous, និង Seek (ទាញនាទី) ដោយផ្ទាល់ពី Lock Screen។

## 🚀 របៀបបើកដំណើរការ (How to Run)

### ១. បើក Server នៅលើកុំព្យូទ័រ
បើក PowerShell ឬ Terminal នៅក្នុង Folder នេះ រួចវាយ៖
```bash
npm start
```
ឬ
```bash
node server.js
```

Server នឹងចាប់ផ្តើមដំណើរការនៅលើ៖
👉 **http://localhost:3000**

## 📲 របៀបតភ្ជាប់ និងស្ដាប់លើទូរស័ព្ទដៃ (iPhone & Android)

ដើម្បីស្ដាប់ចម្រៀងលើទូរស័ព្ទដៃ និងសាកល្បងមុខងារ **Lock Screen**៖

1. ភ្ជាប់ទូរស័ព្ទ និងកុំព្យូទ័រទៅលើ **Wi-Fi តែមួយ**។
2. រកមើល IP Address របស់កុំព្យូទ័រ (ឧទាហរណ៍៖ `ipconfig` -> `192.168.x.x`)។
3. បើក Browser នៅលើទូរស័ព្ទ (Safari លើ iPhone ឬ Chrome លើ Android) ហើយចូលទៅកាន់៖
   👉 `http://IP_កុំព្យូទ័រ:3000` (ឧទាហរណ៍ `http://192.168.1.15:3000`)
4. ចុច **Play** បទចម្រៀងណាមួយ រួចចុច **បិទអេក្រង់ទូរស័ព្ទ (Lock Screen)**៖
   - ចម្រៀងនឹងនៅតែបន្តចាក់ដោយរលូន មិនដាច់ឡើយ!
   - នៅលើ Lock Screen លោកអ្នកនឹងឃើញរូបភាពចម្រៀង ឈ្មោះបទ និងប៊ូតុងបញ្ជាយ៉ាងស្រស់ស្អាត!
